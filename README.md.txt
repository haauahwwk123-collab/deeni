# 🕌 ديني - تطبيق إسلامي متكامل

تطبيق ويب عربي كامل: القرآن الكريم، الحديث الشريف، مواقيت الصلاة، والأذكار.

## المميزات
- 📖 **القرآن الكريم**: الـ 114 سورة كاملة بالنص العثماني، مع تلاوة صوتية بصوت مشاري العفاسي، وبحث في السور
- 📜 **الحديث الشريف**: الأربعون النووية كاملة بالمتون الصحيحة
- 🕋 **مواقيت الصلاة**: لأي مدينة (الافتراضي القاهرة)، مع التاريخ الهجري وتمييز الصلاة القادمة
- 📿 **الأذكار**: أذكار الصباح والمساء مرتبة مع عدد مرات كل ذكر وفضله
- 📱 **يعمل كتطبيق**: يمكن إضافته للشاشة الرئيسية في الموبايل (PWA)، وصفحات القرآن تعمل بدون إنترنت بعد أول قراءة
- 🌙 تصميم داكن أنيق بألوان ذهبية وخضراء

## طريقة النشر (نفس طريقة حمّلها بالظبط)
1. اعمل Repository جديد على GitHub (مثلًا اسمه `deeni`)
2. ارفع الملفات الثلاثة دي فيه (Add file → Upload files)
3. على Railway: New Project → Deploy from GitHub repo → اختار الريبو
4. استنى دقيقتين وهتلاقي الموقع شغال على لينك Railway 🚀

أي تعديل بعد كده: عدّل `app.py` من GitHub ودوس Commit، وRailway هيحدّث الموقع لوحده.

## مصادر البيانات
- نص القرآن: AlQuran Cloud API (النص العثماني)
- التلاوة الصوتية: Islamic Network CDN (مشاري العفاسي)
- الأحاديث: Hadith API (الأربعون النووية)
- مواقيت الصلاة: Aladhan API (طريقة الهيئة المصرية العامة للمساحة)
